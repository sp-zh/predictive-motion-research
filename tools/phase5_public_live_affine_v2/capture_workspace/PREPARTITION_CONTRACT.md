## Fixed supported-envelope receipt policy

For N,T,S=2T,K,addition records J and actual requested capture mode:

`catalogue_role_upper = 32 +16N +12T +23S +20K +3J + (Dense ? 7+7S :0)`.
This is the COMPLETE-descriptor B1 closed requirement-key upper, not a count of
actually captured chunks or a success assertion. Decomposition:

- constant32 includes raw final/metadata/flags, normalized ref, initial boundary,
  compact global fields/selector/chosenkind/evaluation U, topology, all canonical
  concatenation/sum/evaluation roles and decoder/failure groups;
-16N: cell controls/states2N, native cell-map11N, remaining boundary3N;
-12T: cycle stateT +native cycle-map11T;
-23S: substep/friction/clips7S +native substep-map11S +sample recipe/evaluation5S;
-20K term input/used/condensed/original-evaluation roles;3J C/parent rows/sampleID;
-Dense adds7 full L/E/f/I/LU/R/solution fields plus7S selectors/two sample sets.

Policy then allows one extra typed cell-control leaf per cell (alpha/b f64 packed
apart from integer cycles), and EXACTLY32 bounded ancillary numeric receipts for
profile/invocation/forensic compound leaf expansion. This is a STRICT supported
capture envelope, not proof that arbitrary future metadata layouts fit. A B2B
binder must assign every actual full leaf to an allowed role, privately enforce
the total receipt limit, and refuse an insufficient/extra expansion instead of
omitting data or raising this limit. The ancillary envelope includes cached model
numeric metadata/indices, literal context/history/range numeric fields, and
required retained scratch/frontier numeric expansions; nonnumeric complete
metadata/rosters still require actual8MiB/output guards. No full leaf splitter
or receipt-count commit is implemented in this unit.

`receipt_limit = catalogue_role_upper + N +32`

`capture_credit = catalogue20 + max(writerIO20,readerIO28) +4*receipt_limit`.
The same-case IOlease prevents simultaneous writer and reader. Each retained
move-only record keeps its4-axis ticket. Writer IO20 covers cache16+token4;
reader28 covers cache16+private axes4+token8. Token/refill reuse charges remain
required; a live-space grant is not a cumulative/metadata/byte approval.

## Ancillary32 named packing envelope

The finite ancillary quota supports the following declared numeric families;
B2B must privately validate their exact source identities/lengths/packing, not
accept an arbitrary caller-labelled chunk:

1. Cached model numeric metadata: masses/armature/gravity/R/B/damping6, plus
   idx_q/idx_v/joint_nq/joint_nv4; nq/nv may be one i64[2] aggregate (11 receipts).
2. Literal actual invocation initial f64[30], previous accepted alpha/b f64[8],
   actual boundary counters u64 aggregate, static validated q/C lower/upper

3. ORIGINAL SubstepValue cell/cycle/half as ONE i64[S,3] aggregate, separately
   from every RawMapIndices chunk. Value and map index records may differ on
   failure; never omit value indices on the assumption that maps duplicate them.
4. Normalizer current scratch f64[120]; current compact sample workspace; cost
   current active work and persistent direct/condensed scalars; retained stage/
   written-frontier counters as typed bounded aggregates. Only actually defined
   regions are included; already declared L/E/f/I/LU/R/solution/sample arrays
   keep their primary role receipts, not duplicate copies.

These named groups plus any necessary additional known-field split must together
fit the32 limit. Non-numeric names/units/statuses/errors/file rosters/IDs remain
complete metadata and count against actual byte/metadata caps. A wider profile,
unknown source field or inability to losslessly pack EVERY required value MUST
refuse; neither the formula nor this source asserts that full actual leaf
coverage/count enforcement is already implemented. No trimming earns success.

Observer applied/allocated_work describes allocation that OCCURRED. The observer
holds private origin/case/snapshot state, NOT CostStorage or its numerical buffer.
After CostStorage is destroyed, that history cannot authorize IO or prove current
live workspace. B2B must keep the SAME genuine source owner alive, require current
nonrefused/current mathematical/capture validity, compare sameCase, and actually
budget.reserve every child object. No observer alone mints a buffer lease, credit
increase, fullFlowAccepted or root READY.
