## Typed strings and lifetime

UTF8 validation rejects overlong/truncated sequences, surrogates, invalid leads
and codepoints above U+10FFFF before handing text to the visitor. Empty strings
and embedded control/NUL bytes are retained by length and JSON escaped; invalid
UTF8 refuses this encoder without rewriting the held original bytes. Arbitrary
non-UTF8 process/error bytes will need an explicitly typed opaque archive branch,
never lossy transcoding. Each text is bounded by the fixed8MiB metadata cap before
any copy; the interface borrows strings, arrays and descriptors rather than
building a DOM or resident registry. U64/I64/bool remain typed. IEEE64 bit values
remain exact U64 bit payloads under distinct Ieee64Bits kind plus scalar kind,
including signed zero/NaN payload; no floating conversion is performed.

Metadata/reference/coverage views are noncopy, private-constructor and active
for one exact evidence generation. Saved pointers or string_views cannot outlive
the callback/owner (dereferencing a destroyed C++ view is outside its lifetime,
not detectable by a generation check). All sinks are frozen local copies AFTER
active scope is set; copy/empty/reentry/standard/nonstandard exceptions latch
first independent evidence refusal, also first capture refusal for a live session.
Failed/closed sources may be inspected without clearing source errors, reopening
capture or enabling export. Reentry into numeric/forensic/source attach/consumer
issuance/sample/close is denied. An already refused evidence stream cannot retry.

The optional string-only encoder streams exact quoted UTF8 JSON fragments. It
reserves its 1-slot six-byte escape buffer before materialization and charges
actual encoded metadata bytes BEFORE each callback, with no refund on failure.
Each fragment may split a multibyte scalar; their ordered concatenation is UTF8.
It does not encode a complete metadata record or charge unique file output bytes.
The future single owner file writer must separately charge each actual unique
output byte once and all additional metadata punctuation/scalars, without double
charging these string bytes. Repeated string encoding consumes additional real
metadata charge; no successful byte/READY claim is made by this source core.
