# Controller geometry and independent plant observation

The controller reads an offline model/configuration and measured joint positions. `Scene` accepts configured link frames, meshes, tool frame and fixed world primitives. It has no MuJoCo pointer or plant future. The FR3 diagnostic uses arm-only official URDF kinematics, Menagerie collision convex hulls and all five tool primitives: adapter, shaft, sensor, tip and side bracket. All four channel components and the floor remain present. No fixed hand is retained.

Convex meshes preserve every Menagerie STL vertex; SciPy/Qhull generates oriented faces without simplification. Each generated asset records original/generated hashes and vertex containment residual. MoveIt loads the same hull surfaces. Runtime Coal 3.0.3 queries use signed distance, GJK/EPA 1e-10 tolerance and 256 GJK iterations. A result must have finite distance/witnesses/normal, unit normal and `p_b-p_a=d*n` within 1e-6m. The gradient is `-n^T*(Jpoint_a-Jpoint_b)`, where `Jpoint=Jlinear + Jangular cross (point-frame_origin)`. The point Jacobian is validated against independent position finite differences.

Box tool primitives are partitioned into cells no wider than 4mm per axis, each enclosed by its circumsphere. Each cylinder is partitioned axially into slices no wider than 4mm; a slice of radius r and axial width delta fits inside an axis-centered sphere of radius `sqrt(r*r+(delta/2)^2)`. These slices cover the complete cylinder including caps. The tip uses its exact sphere. Boxes have inflation bounded by each circumsphere radius; a cylinder slice has inflation bounded by `sphere_radius-min(r,delta/2)` because the slice contains that centered inner ball. Analytic coverage is the proof; seeded boundary/interior samples are additional checks. `cover_enclosure.csv` records the actual per-primitive counts, sample counts, maximum sample gap, radius and bound. Previous dense-grid development evidence is preserved with its source hashes.

Sphere-center/box distance is smooth outside the convex box because the Euclidean projection is unique, including the original parallel tool-face cases. Each sphere/fixture and sphere/floor constraint remains separate. Inside a fixture the evaluator returns signed penetration, while gradient requests reject unavailable safe derivatives. Full original primitives independently evaluate tool/arm/fixture/floor clearance; the cover does not replace the physical tool. The common safety supervisor imposes the same cover checks on all methods, including real Servo.

All arm/environment, nonadjacent arm self and tool/arm pairs are queried. Exclusions are adjacent kinematic arm links, the fixed tool/last-link assembly, intra-tool/intra-fixture fixed compounds, static/static world pairs and intentional base/floor mounting. The tool/penultimate-link pair remains checked. The raw minimum true clearance includes all queried pairs; the tool/environment minimum is separately reported when comparing cover conservatism.

All distances are computed before pruning. To omit a far damper row, the adapter uses a global model-derived joint-to-point radius bound R. A joint step delta moves a point by at most `R*sum(abs(delta))`; two moving objects are bounded by twice this. The active threshold is the larger of 30mm and `safe + 2*R*(sum(abs(accepted_q-measured_q))+7*trust_step) + epsilon`. Joint command steps are bounded by the same frozen trust step. Thus a pruned pair cannot cross the safety distance under either measured-state extrapolation or target displacement. This does not bound physical actuator acceleration or provide continuous collision certification.

Convex/true-primitive feature ties are retained. The independent probe reports smooth central derivatives, nonsmooth one-sided intervals and actual checked component counts. Unchecked poses are marked NaN with zero checked counts, not zero measured error. Every accepted candidate and stop undergoes four kinematic subdivisions along both measured-state and persistent-target updates. These are model checks, not a MuJoCo future rollout, and not a continuous safety proof.

An independent scratch `mjData` copies the current full plant state and runs `mj_forward` after each actual 2ms `mj_step`. It evaluates contacts and full true geometry and checks TCP/all-arm-frame alignment with Pinocchio. Every observation compares the live `mjSTATE_INTEGRATION` before and after; any mutation is an explicit error. Creating the Plant with a 2ms period and advancing it twice preserves the original plant integrator sequence without changing its core implementation.

The installed FCL backend crashed when an infinite plane was paired with meshes. Servo uses an 8x8x8m floor box centered at configured `floor_z-4`, rather than a shallow floor slab. With `abs(floor_z)+R<2m` (checked at startup), it encloses every reachable below-floor point; its side and bottom faces are farther than its top throughout the reachable region. The current model-derived bound is recorded in geometry.json. This preserves the halfspace collision/nearest-top interpretation on the supported reachable region. Plane crash and shallow-slab development attempts remain in the evidence history.
