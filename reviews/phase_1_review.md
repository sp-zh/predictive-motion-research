# Phase 1 kinematics review

Decision: **PASS**. Reviewed by the Mac coordinator from actual source, exported numerical data, an independently triggered build, installed-package checks and integrated CI execution. Scope is kinematics correctness for the pinned FR3 model, not predictive-control or collision performance.

## Completed scope and evidence

`predictive_motion_kinematics` implements C++ Pinocchio FK, configured joint order and fixed hand joints, joint limits, world/base/flange/TCP transforms, LOCAL and LOCAL_WORLD_ALIGNED Jacobians, SE(3) log residual, joint residual Jacobian and desired-body residual derivative. Mathematical code has no ROS headers or MuJoCo dependency; MuJoCo is a test comparator only. Data workspaces are instance-local and cannot be shared between concurrent calls.

Official `franka_description` commit `7aeeddc449edf8d62b594f9e36a81da53e7796f9` supplies generated URDF and preserved xacro/YAML source, licenses and notices in `models/fr3`. Only an autogenerated absolute-path comment is normalized. Menagerie plant commit is `4d038b3feae26ec82b46a4d586379114012a8ac7`. Flange is link7 followed by 0.107 m along Z; configured TCP is another 0.32 m along flange Z. No empirical frame correction is present.

`results/phase1/numerical/samples.csv` contains 2,000 random valid configurations, seed 42, explicit mt19937 integer mapping and 2% margin inside the URDF/plant limit intersection. Central finite differences use h=1e-6; translation and rotation are differentiated separately, with SO(3) log for rotations. Each sample records absolute and relative Frobenius errors. `summary.json` records mean, median, p95, p99 and worst case; `epsilon_scan.csv` scans four step sizes on the first 50 configurations.

Relative denominators use a declared 1e-12 floor; absolute error is retained near zero. The zero-coordinate structural comparison is separate from operationally valid samples because some zero coordinates are outside robot limits.

Seven C++ GTest cases cover limits/fixed hand, xyzw quaternion convention and invalid inputs, rotated base and tool offset, near-pi reconstruction/branch behavior, joint-order permutation, invalid dimensions/frames/reference enum and near-pi desired-body derivative away from the cut. Colcon reports eight aggregate tests including its wrapper, with zero failures/skips in `test-results.log`. Differentiability exactly across the pi branch cut is explicitly not claimed.

`installed-smoke.log` proves installed config and bundled URDF load from `/tmp`; `consumer.log` proves a separate CMake consumer links the exported mathematical library. A separate Linux source directory re-fetched/rebuilt/tested (`clean-validation.log`). Mac independently built with separate build/install prefixes, used installed config from `/tmp`, re-ran all 2,000 numerical samples and obtained byte-identical `samples.csv` (`root-independent-run.log`). This independent build preceded the additional permutation test; the final normal/clean/integrated runs include it.

Finally, `scripts/ci.sh` executed Phase 0 ROS command/state/reset tests followed by Phase 1 fetch/build/unit/numerical/installed/consumer checks successfully (`integrated-ci.log`). The container and hosted workflow call the same entrypoint but remain unexecuted.

## Review findings and fixes

- Fixed installed config resolving a source-only URDF path; generated models now install beside the config.
- Require finite, ordered retained-joint bounds, finite/dimensionally valid coordinates, valid SE(3) transforms and explicit valid Jacobian reference enum.
- Fixed public package license metadata to distinguish original MIT code from preserved Apache-2.0 model assets. Numerical code is unchanged by this metadata correction.
- Preserved configured joint-name order and tested a nontrivial permutation.
- Explicitly distinguish LWA TCP-origin velocities from WORLD spatial twists; no silent WORLD substitution.

## Known issues, technical debt and scientific risks

Kinematics functions permit finite out-of-limit coordinates for differential evaluation; physical command checks must remain at the command boundary. The shared velocity/acceleration/jerk monitor, stale-state handling and smooth failure behavior are still future control work. Exact pi residual discontinuity needs an explicit controller policy. The strict quaternion parser requires full-precision unit quaternions.

Matching FK/axes does not validate dynamics, collision geometry, actuator response, hardware calibration or solver performance. Gripper joints are fixed; arm-only task equivalence does not certify hand collision equivalence. iiwa cross-validation, FreeCAD-to-robot integration, collision-distance fidelity and all comparative controls remain outstanding.

The clean rebuild reused installed OS dependencies; Docker/hosted CI and a fresh OS reconstruction remain open under ENV-003. WSL tests do not establish a 250 Hz hardware real-time guarantee. Numerical random samples do not establish statistical benefit of a controller.

The Phase 1 gate permits Phase 2 IK baseline development. Later phase gates remain closed.
