## Actual bytes, file identity and independent reader

Absolute root components are bounded/safe and opened directory-by-directory with
nofollow. Relative name is one bounded safe .provisional component. Writer creates
O_EXCL|NOFOLLOW|CLOEXEC0600, requires a fresh empty regular single-link FD, and
records directory/file dev/ino. Before every physical flush it checks pending
metadata and output caps. It counts/charges UNIQUE OUTPUT and ENCODED METADATA
once per actual successful shortwrite byte, and hashes exactly those same bytes.
Partial/zero/error writes preserve physical bytes, pending bytes, hash validity,
source event/field cursor and first error; no delete/overwrite/retry/rename.
File and directory fsync plus unchanged FD size/dev/ino/single-link required for
closedProvisional. Paths/retained observation identities separately charge their
bounded stored-metadata allowance before copies; first error copies max512 bytes
also charge before allocation, otherwise explicit fallback and genuine source
first-error evidence remain. Source strings never enter unbounded copies.

The private writer branch borrows MetadataLeafView.fact().text and performs its
own accounted UTF8 JSON encoding. It never calls the already-charging B3A
withJsonString, never subtracts/refunds its charges, and no caller can choose a
skip flag. Every emitted punctuation/scalar/string byte is charged by successful
FD write once. Reader does not count these encoded output bytes a second time;
its actual buffers/copies/scratch and retained diagnostic metadata are separately
charged. This preserves original aggregate metadata cap rather than raising it.

Reader uses a new O_RDONLY|NOFOLLOW|NONBLOCK FD and separately checks directory/
file identities, size and regular single-link type. Independent handwritten
strict parser does NOT call writer formatter/escape/type-label logic. It parses
canonical typed tokens, decodes/validates raw UTF8 and escaped surrogate pairs,
and compares every exact primitive/string/IEEE-bit/reference/coverage field to
fresh private source borrows and immutable quota snapshot. Buffer read-ahead SHA
and consumed cursor are separate; exact advertised bytes, actual physical EOF,
unchanged FD and independent whole SHA==private actual writer SHA are required.
Same low-level safe-path/hash primitives are shared, not parser/formatter logic.
An external NumericChunkRecord/hash/file count cannot enter this reader authority.

## Explicit failure strategy and unresolved gates

Live mode requires current complete unrefused actual source and applied V2.
Failure mode requires actual closed/refused/incomplete source AND historical actual
V2 reduced allocation still genuinely held by the same cost owner. Historical
applied is used only for legal diagnostic headroom, never to restore capture.
Preallocation/open/pre-affine/earlier missing owners are refused without file IO.
A failed live attempt cannot retry under failure mode; failure after creation keeps
that exact provisional artifact/partial SHA/cursor/source errors. No cleanup.
Readonly status never enables numeric export, arithmetic replay or new Model call.
