# Prospective rank-consistent hint source review

The old hint rejected every rank-deficient active-face KKT matrix. The new source retains every active face and Eigen FullPivLU default rank threshold; it accepts a finite consistent solution only under the original complete residual 1e-10. Singular cases additionally require the original primal Hessian symmetry gate, successful floating LLT with finite positive diagonals and reported rank at least the primal dimension. Final original all-row primal 1e-12 and stationarity 1e-10 gates remain mandatory, followed by native SOLVED, complete original SI, literal history, nonlinear B and private C gates. The hint is bounded at 512 iterations and 10 seconds.

For an exactly symmetric positive definite H and consistent full active constraint system, the primal component of the KKT solution is unique: a homogeneous difference obeys A d=0 and H d+A^T delta_lambda=0, hence d^T H d=0 and d=0. Multipliers can be nonunique. Floating LLT/rank/residual tests are numerical guards, not a rigorous conditioning or exact arithmetic certificate. No convergence, unrestricted original-QP optimum or nonlinear safety claim follows.

Retries use only the controls of an eligible refused candidate as the next genuine Model nominal, preserving the actual state and accepted history. Each trial has new native maps, full geometry, QP, solver and B checks. No retry occurs after a private validation token has been issued. The code latches physical completion and ledger completion immediately after successful C and before receipt/evidence writes; a subsequent evidence failure still fails the overall entry. Saved actual chains, fault tests and source identities need their separate full review.
