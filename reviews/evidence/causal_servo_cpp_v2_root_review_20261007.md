## Mathematical contract

State order is `(physical q/v, accepted target c/velocity w, progress s/r)`, control `(command alpha, progress b)`. Each 4 ms cycle first updates `w+=h*alpha`, then `c+=h*w_next`, with two 2 ms physical updates under that held target. Physical measured v is not substituted for accepted w. Progress uses `s+=h*r+.5*h²*b`, `r+=h*b`. A cell holds its control across an integer number of actual cycles; positive mesh durations must be integer 4 ms multiples within the declared `1e-12` representation tolerance, with count capped at 100000.

For each scalar physical step, gain is `g=.002/(m+.002*D)` and interior indicator is `I=1` only if `abs(drive)<eta`. The code correctly uses `dv/dq=-g*kp*(1-impedance*I)`, `dv/dc=-dv/dq`, and `dv/dv=1-g*((1-impedance*I)*D+impedance*I*m*decay)`, then derives position rows from `q_next=q+.002*v_next`. Composition uses `A_next=P*A`, `B_next=P*B`, `d_next=P*d+f`; repeated same-control cells use `B_next=A_step*B+B_step`. Horizon maps accumulate each cell's B into the proper control block. The affine defect includes nonzero bias and clipped-force offsets. These are the expected scalar-model equations.

At exact ±clip thresholds the module selects the saturated-side Jacobian, matching the packet. Both artificial threshold fixtures count one equality and switch to interior on the second physical substep. This is a declared convention at a nonunique derivative, not an ordinary central-FD result. The six smooth fixtures cover interior and both saturation signs; their n7 branch vectors are uniform across joints. Mixed-vector branch combinations were not exhaustively tested.

## Reproduced public API defect

Model validation now checks vector dimensions/finiteness and parameter signs before Eigen operations; domain checks run before/after the command and both physical updates. Those fixes are valid. However, only the returned physical state is domain checked: transition A/B/defect are not checked for finite derived arithmetic.

An isolated n1 case with finite accepted parameters `mass=1e-300`, `kp=1e308`, `D=0`, `friction=0`, `impedance=.9`, `decay=100`, zero bias/control/q/v/c/w and progress `.2,0` passes `Model::validate` and returns without an exception. Returned state is finite, but A, B and defect are nonfinite. The gain-times-stiffness derivative overflows although the nominal force/state stay zero. The standalone counterexample consumer and fresh flags are retained; this is an executed API counterexample, not a reconstructed original production failure.

Smallest correction: reject nonfinite state, A, B and defect before returning a public transition, including cell composition; alternatively enforce and document an arithmetic parameter envelope that excludes this case. Do not change frozen FR3 coefficients or physical limits to address it. This defect is outside the frozen-model tests and does not undo their parity; it limits the broader generic API robustness claim.

The module deliberately does not enforce command velocity/acceleration/jerk history, joint position/geometry guards, a stopping policy or solver acceptance. Model-box membership is not an accuracy certificate. Scalar-model v3 larger-input failures remain retained, and this component is not the proposed coupled public-dynamics predictor. No timing claim follows from these isolated tests.
